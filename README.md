## 📌 Project Overview

This project is a fully interactive **Pharmaceutical Inventory Analytics Dashboard** built using **Plotly and Python**.

It simulates a real-world medical inventory system used by:

- Pharmacies  
- Hospitals  
- Medical distributors  

The dashboard helps in:

- Monitoring stock levels
- Tracking expiry risks
- Analyzing pricing patterns
- Identifying high-value medicines
- Comparing inventory across categories, brands, and suppliers

⚠️ This is designed to closely reflect **practical healthcare inventory analytics use-cases**, not a toy dashboard.

## 🔍 Key Features

### 📊 Inventory Analytics
- Total inventory value calculation
- Category-wise and brand-wise stock distribution
- Top medicines by stock value

### 💰 Pricing Insights
- Violin plots for unit price distribution
- Outlier detection across medicine categories

### ⏳ Expiry Monitoring
- Inventory trend by expiry month
- Early identification of expiring stock

### 🔎 Smart Inventory Lookup
- Search medicines by name
- Filter by category, brand and supplier
- Sort by:
  - price
  - quantity
  - expiry date

### 📈 Pivot & Comparison Analysis
- Dynamic pivot tables
- Side-by-side category comparison
- Conditional formatting for quick insights

## 🧪 Dataset Details

- **Total Records:** 500 medicines
- **Categories:**
  - Tablet
  - Capsule
  - Syrup
  - Injection

### Attributes

- Medicine Name  
- Category  
- Brand  
- Supplier  
- Unit Price  
- Quantity  
- Expiry Date  
- Batch Number  

The dataset is synthetically generated to mimic **enterprise-level pharmaceutical inventory systems**.
